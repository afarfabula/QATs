## Recipe

- Model: Swin-T W4A4 OFQ QAT
- Data: ImageNet parquet at `/tmp/imagenet1k_full_parquet`
- Devices: 8x H100
- Per-GPU batch: 256
- Global effective batch: 2048
- Quantization:
  - `--wbits 4 --abits 4`
  - `--wq-mode statsq --aq-mode lsq`
  - `--wq-per-channel --aq-per-channel --aq-clip-learnable`
- Initialization:
  - `--pretrained --pretrained-initialized`
  - QAttention Swin modules copy pretrained `qkv`, `proj`, and `relative_position_bias_table` from the source attention module.
- Training:
  - KD enabled with hard+soft KD: `--use-kd --kd-hard-and-soft 1`
  - Teacher: pretrained Swin-T checkpoint `swin_t-704ceda3.pth`
  - No augmentation for the fast stage1 recipe: smoothing/mixup/cutmix/aa/color-jitter/reprob disabled.
  - bf16 AMP enabled.
  - No qk-reparam.
  - No stage2 KL in this run: `RefAttnKL=0`, `AnchorRefAttnKL=0`.
- Optimizer/schedule:
  - `--lr 2e-4 --min-lr 1e-5 --weight-decay 0.0`
  - `--no-resume-opt` when continuing from the 10-epoch ckpt.

## Infrastructure changes used by this run

- Fast distributed full validation for parquet ImageNet:
  - validation data is rank-sharded;
  - rank metrics are all-reduced;
  - rank0 reports global Top-1/Top-5/loss/sample count;
  - each rank processes 6250 samples for the 50k validation set.
- bf16 AMP and reduced synchronization overhead in the unified OFQ launcher.
- Quantizer hot-path cleanup to avoid unnecessary GPU-to-CPU sync and repeated scalar tensor allocation.
- Bias broadcast micro-optimizations in quantized modules.
