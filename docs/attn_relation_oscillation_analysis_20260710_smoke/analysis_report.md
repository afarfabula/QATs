## 使用指标

- `js_divergence`: 平均 attention relation 分布的 JS divergence
- `cosine_distance`: 平均 relation matrix 的 cosine distance
- `topk_overlap_change`: 每个 query 的 top-k key 集合变化
- `entropy_delta`: head attention entropy 变化
- `oscillation_score`: 综合震荡分数
- `spike_score`: 最大震荡 / 平均震荡
- `reversal_score`: 震荡强度方向来回变化的近似指标
- `post_peak_drop_score`: checkpoint-52 以后与精度回落相乘的风险分数

## 对 10->110 dynamic sparse prev-step KL 的建议

1. 不要再固定压制 49-52 的自然高点窗口。
2. 只在验证精度低于 rolling best 且 head 的 harmful score 排名前列时触发 KL。
3. 每次最多约束 1-2 个 head，weight 从 `1e-5` 起，上限 `3e-5`。
4. 对 beneficial drift heads 设置 cooldown 或黑名单，避免压掉原版 OFQ 的自然上冲。
5. 后续 10->110 的候选策略应偏向高点后稳定化，而不是高点形成前约束。
