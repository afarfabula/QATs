## 4. ⚠️ 踩过的坑（最重要的一节）

### 4.1 LSQ 的 `s` 是懒创建的 —— 离线评估必须"先 setup_alpha，再 load"

`LsqQuantizer.__init__` 里 `register_parameter('s', None)`，真正的 Parameter 在**第一次 forward**（或 `setup_alpha`）时由 `init_from()` 建立。因此：

```python
# 错误（会得到完全错的数）：load 时 s 还不存在，strict=False 静默跳过
load_checkpoint(model, ckpt, strict=False)
model(x)

# 正确：先跑 1 个 batch 把 s 建出来，再 load
ql.setup_alpha(model, loader_train, runtime_args, amp_autocast)   # 1 batch
load_checkpoint(model, ckpt, strict=False)
```

正确实现的现成脚本：`tmp_scripts/diagnose_attention_correct_order_20261119.py`（原来在 `/tmp/attn_fix.py`）。
判据：`len([n for n,_ in model.named_parameters() if n.endswith('quan_a_softmax_fn.s')])` 应为 12。

### 4.2 top-k recall 不能用离散索引

`topk(...).indices` 不可微 → 损失梯度为 0，训练与对照逐位相同。必须用可微替代：教师 top-k 支撑上的**学生概率质量**

```python
mask = zeros_like(p).scatter_(-1, teacher_topk_idx, 1.0)
loss = 1 - ((p * mask).sum(-1) / p.sum(-1).clamp_min(1e-8)).mean()
```

### 4.3 长跑脚本强制 4 ranks

`run_deit_tiny_w2a2_*.sh` 里有 `if [[ NPROC -ne 4 ]] → exit 2`。别试 2 卡。

### 4.4 `--attention-quant-*` 不是 qat_launch 顶层参数

要写成 `--extra-arg=--attention-quant-weight --extra-arg=9.10`（`--teacher-attn-kl-*`、`--lsq-scale-floor` 则是顶层参数）。

## 6. 机制解释（当前的理解，写论文可直接用）

1. 后 softmax 的 2-bit 量化把注意力变成稀疏张量（基线 mass 0.502、59% 归零）。
2. 对 **FP 教师**做 KL：目标稠密、学生稀疏 → 不可达；而且 `s` 是自由参数，优化器选择"把 `s` 缩小 → 整表趋零"，KL 降了、形状勉强像了，但注意力模块被压哑（mass 0.0074）→ 精度零增益。
3. 把**目标也量化**（同一套 `s`）→ 两侧同域，KL 447→~12，可达；再**冻结 `s`** → 掐掉缩尺度捷径。此时只能真的把概率质量搬到教师的 top-k 支撑上，top-5 重合 16.5%→33.5% 才转化为精度。
4. 冻结还有一个副作用是好的：目标用的是学生自己的量化器，`s` 冻结后目标才静止（否则是移动靶）。

**未验证/待验证**：这条增益到底来自"注意力更像教师"，还是来自"冻结 `s` 顺带阻止了尺度漂移"。20ep 跑完要用正确口径测 C 的 KL / top-5 / mass / `s` 分布来分离这两者。

## 8. Q-ViT 撞车评估（结论先行）

**有风险，但不是全撞。**

- Q-ViT（NeurIPS 2022，[arXiv:2210.06707](https://arxiv.org/html/2210.06707v1)）的核心：诊断"低比特下 attention map 信息失真是瓶颈"（量化 q/k/v+attention 掉 10.03%，量化 MLP 只掉 1.78%），用 **IRM**（q/k 上可学习重参数化、最大化量化表示的熵）+ **DGD**（用**相似性矩阵**做蒸馏，区分 pre-/post-LayerNorm）解决。
- **撞车点**：「量化 attention 是瓶颈 + 用教师注意力监督」这个动机是它的，不能算我们的新意。
- **需核实**：Q-ViT 的 DGD 里教师是 FP 还是量化后的——论文正文措辞是 "full-precision counterpart"，但**未确认**（PDF 抓不到全文，只拿到 HTML 前 30k 字符）。**必须去核 §4.3 与消融表**；如果它也用量化教师，我们就不能主张这一点。
- **我们能站住的三点**：
  1. **A vs C 的对照**（同协议、同 λ、同 head）：FP 教师目标 = 53.004 零增益，量化教师目标 = 稳定 +0.4 → 把"目标可达性"变成一个被量化的事实。
  2. **冻结/切断 `s`** 这条反作弊机制，以及"负 LSQ 步长、mass 塌到 0.007"的实证诊断；Q-ViT 是用前向 IRM 达到类似目的，两者可并列讨论，甚至可组合。
  3. **W2A2（2-bit）** 这个极端设定下的形态（59% 归零、行质量 0.5）。
- 相关工作建议写法：Q-ViT = IRM（前向保熵）+ 相似性矩阵蒸馏；我们 = 把"目标的可达性"和"量化步长的自由度"分开处理，给出 2-bit 证据。
