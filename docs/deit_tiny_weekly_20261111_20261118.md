## 3. 批次 B：逐 block 位宽 profile（本周主产出）

### 3.1 结果表

`T` = 真实三值 `{-1,0,1}`（softmax 用非负 `{0,s,2s}`），按 `log2(3)=1.585` 记有效 bit；patch/head 恒为 W8A8。

| 实验 | Block profile | 有效 bit/block | Final Top-1 | Final Top-5 | vs W2A2 |
|---|---|---:|---:|---:|---:|
| W2A2 baseline | `[2]×12` | 2.0000 | 53.004 | 77.154 | — |
| **left33 oneside** | `[3,3,T,T,T,T,T,T,T,T,2,3]` | 1.9733 | **53.528** | 77.550 | **+0.52（更少 bit）** |
| **right33 oneside** | `[3,2,T,T,T,T,T,T,T,T,3,3]` | 1.9733 | **53.516** | 77.556 | **+0.51（更少 bit）** |
| 3/2/T H-L-H | `[3,2,T×8,2,3]` | 1.8900 | 52.628 | 76.716 | −0.38（−5.50% bit） |
| 3/T H-L-H | `[3,3,T×8,3,3]` | 2.0566 | 54.948 | 78.512 | +1.94（+2.83% bit） |
| **4/3/2/T 双侧** | `[4,4,3,2,T,T,T,T,2,3,4,4]` | 2.6950 | **61.638** | **83.740** | **+8.64（+34.8% bit）** |

### 3.2 三条可用的结论

1. **最好点**：`[4,4,3,2,T×4,2,3,4,4]` = 61.64 / 83.74，比 W2A2 高 8.64，比 3/T 高 6.69，而有效 bit 仍比 uniform W3A3 低 10.17%。
2. **干净的 Pareto 点**：`left33` / `right33` 用 **1.9733 bit（比 W2A2 少 1.3%）** 拿到 53.53，**在更少 bit 下反超 uniform W2A2**。这是本周唯一“既省又准”的严格占优点。
3. **左右对称性不重要**：left33 与 right33 差 0.012（完全同分布内），说明“哪一侧肩部多给 1 bit”无所谓；真正起作用的是**两端肩部整体抬到 3 bit**（3/T 比两个 oneside 高 1.4）。
4. **逐 bit 边际收益单调递减但始终为正**：1.89→52.63、1.973→53.53、2.00→53.00、2.057→54.95、2.695→61.64。前两个 4-bit + 两个 3-bit 的加宽（2.695）一次性买到 +8.6，说明**首尾 block 位宽是主要矛盾**。

### 3.3 缺的控制（重要）

- **同协议 uniform W3A3 从未跑**（计划里写着“待跑”）。没有它，61.64 不能宣称“混合位宽优于均匀 3-bit”，只能说“优于 W2A2”。
- 同协议 uniform W4A4、`[4,4,4,2×6,4,4,4]` H-L-H 也未跑。
- 所有 profile 都是单 seed，±0.18 是单点二项标准误，但相邻 epoch 强自相关，**+0.5 级别的差不要当显著**。

## 4. 批次 C：注意力量化诊断与四条约束

### 4.1 同 checkpoint 的推理期消融（11-17，基线 `last.pth.tar`）

| 注意力路径 | Top-1 | Top-5 |
|---|---:|---:|
| 原样（2-bit LSQ 量化，**不做行归一化**） | **53.004** | 77.154 |
| 量化后强制行归一化 `--attention-softmax-post-quant-renorm` | 23.142 | 43.914 |
| 直接换成 FP 注意力 `--attention-softmax-fp` | 14.392 | 30.152 |

**这是本周最重要的单条现象**：训练好的 W2A2 网络**依赖**那个“未归一化、质量不足 1”的量化注意力矩阵。两条互不相干的代码路径（renorm / 换 FP）都把行质量拉回 1，精度就分别掉到 23 / 14。

### 4.2 我现场复测的量化注意力统计（8 batch×32 图，post_quant hook，12 层）

| checkpoint | pre 行质量 | post 行质量 | 零元素占比 | 行内 ≥80% 为零的行占比 |
|---|---:|---:|---:|---:|
| W2A2 基线（53.00） | 1.0000 | **0.6028** | **81.2%** | 53.0% |
| `teacherattnkl`（53.00） | 1.0000 | 0.6026 | 82.2% | 57.5% |
| `attn_rowmass`（50.54） | 1.0000 | 0.7198 | 72.3% | 6.4% |

逐层看，基线中间层最惨：layer 3 行质量只剩 **0.317**、top-5 质量保留率 **21%**、99.8% 的行 ≥80% 元素被清零；layer 0/10 还有 0.75，呈“两头好、中间塌”的形状。

> 也就是说：**W2A2 下的注意力在做“稀疏路由”，而不是在做归一化注意力**，网络已经围绕这个稀疏化重标定了残差尺度。任何部署实现只要按常规对 softmax 输出做行归一化（多数硬件/编译器都会），这个 checkpoint 直接失效。

### 4.3 四条针对性实验，全部没跑赢

| 实验 | 改动 | 校准权重 | Final Top-1 | Δ vs 53.004 |
|---|---|---|---:|---:|
| `teacherattnkl_t2_5pct` | 量化后注意力对 FP teacher 做 KL（block 8-11，三头，T=2） | λ=1.064e-3（5% loss 占比） | 53.004 | **±0.000** |
| `preqattnkl_t2` | 同上但作用在**量化前**注意力（T=2.0） | λ=1.077e-3 | 52.800（19ep） | −0.20 |
| `attn_loguniform` | 换非均匀 4 电平 log-uniform softmax 量化器（前 20 step 校准后固定） | — | 51.510 | −1.49 |
| `attn_rowmass` | 量化后行质量正则（JSD=0，mass weight=1） | λ=9.10（等价 5%） | 50.544（19ep，24 508 s） | −2.46 |

- **teacher attention KL 精确等于基线**（53.004 vs 53.004，连 Top-5 都几乎相同）：它只约束了归一化后的“形状”，没碰行质量，所以对 4.2 的病根**没作用**。
- **pre-quant KL** 更没意义：作用在量化前，量化器照旧把质量扔掉。
- **log-uniform 码本**改的是分辨率，反而更差，说明问题不在“电平取值不优”。
- **rowmass 确实把零占比从 81% 压到 72%、行内死行从 53% 压到 6%**，代价是注意力熵被推到 4.0~5.1（接近 log 197 ≈ 5.28 的上限，即趋于均匀），信息被打散，精度 −2.46。

### 4.4 由此得到的机制判断

注：两条注意力 KL 实验（`teacherattnkl_t2_5pct` / `preqattnkl_t2`）的注意力 KL 温度均为 **T=2.0**，是本周唯一使用 T=2.0 的两条；其余实验的对数 KD 温度统一为 T=1.0。上图以 ★ + 斜纹标出这两条。

注意力量化的损失**不能靠后验正则补回来**：网络已经把“质量塌缩”当成一个可用的自由度在用（等价于给注意力输出乘了个 <1 的增益，层内 LayerNorm/残差自行吸收）。要么在**训练一开始**就用归一化/行质量的量化器（等价于换一个更“硬件正确”的参数化，接受 −2.5 的代价换可部署性），要么承认“非归一化注意力 + 稀疏化”本身是这套 2-bit 方案的一部分，并在方法里明确写出来。

## 三·附：学生到底有没有学到教师的注意力分布？

> 结论：**训练日志里的 KL 确实在降（−17%），但离线同口径测量显示学生-教师注意力 KL 一点没降、反而略升（3.641 → 3.668）。也就是说学生并没有真正学到教师的注意力分布，训练内那条下降曲线主要来自全局尺度/锐度的自然漂移。**

### A. 训练内 TeacherAttnKL 曲线（日志实测）

两条 KL 实验（`teacherattnkl_t2_5pct` 与 `preqattnkl_t2`，KL 温度均 T=2.0）在日志里都单调下降：

| epoch | post-quant KL（block 8-11 三头） | pre-quant KL |
|---|---|---|
| 0（峰值） | 779.70 | 779.70 |
| 1 | 72.91 | 73.76 |
| 5 | 66.54 | 72.50 |
| 10 | 63.17 | 66.59 |
| 15 | 61.06 | 62.50 |
| 末轮（19 / 18） | **60.19** | **61.12** |

- 从 epoch 1 的 72.91 到末轮 60.19，降幅 **−17.4%**；pre-quant 版 73.76 → 61.12，**−17.1%**。
- 最大的那一段下降发生在 epoch 0 内部（779.70 → 83.55），那是 warmup 期的尺度崩塌修复，不是学习。
- epoch 4 之后两条都进入很平缓的线性下降，看起来“在收敛”，但下面这一步才是关键。

### B. 离线同口径复测：KL 没降，反而略升

用同一个 `diagnose_deit_attention_quant_vs_teacher_20261117.py`（25 batch × 32 图，12 层平均，同批 clean val 图）对三个最终 checkpoint 重新量「学生注意力 vs 教师注意力」的 KL：

| checkpoint | KL @T=1 | KL @T=2（训练用的温度） | Final Top-1 |
|---|---:|---:|---:|
| W2A2 基线（完全没加注意力 KL） | 9.054 | **3.641** | 53.004 |
| `teacherattnkl_t2_5pct`（加了 post-quant KL） | 9.223 | **3.668** | 53.004 |
| `preqattnkl_t2`（加了 pre-quant KL） | 9.238 | **3.671** | 52.800 |

- 加 KL 之后学生离教师**更远**了：T=2 时 +0.7% / +0.8%，T=1 时 +1.9% / +2.0%。
- 三个 checkpoint 的注意力统计几乎一模一样：零元素占比 81.5% / 82.3% / 82.4%，量化后行质量 0.603 / 0.603 / 0.604，注意力熵 3.9 / 3.9 / 3.9。
- 精度 ±0.00，与“没学到”完全一致。

### C. 为什么“损失在降”却是“没学会”

1. **KL 被尺度项主导**：`retemper_attention_prob` 会把两侧都重归一化到单位质量，但注意力整体的锐度（温度效应）会随训练漂移；学生只需要跟着把分布整体“软一点/硬一点”，KL 就能掉十几个点，而不需要真的把概率质量搬到教师关注的位置。
2. **量化把可迁移的部分直接碾掉了**：post-quant 注意力 81% 元素为 0、行质量只有 0.60，中间层（layer 3）几乎全灭。KL 只能在剩下的 19% 支撑点上做文章，天花板很低。
3. **梯度预算太小**：λ=1.064e-3 只占 5% loss 份额；主目标 CE+KD 的梯度占绝对主导，20 epoch 内不足以改变注意力形状。
4. 旁证：同批实验里，把 KL 作用在量化**前**（pre-quant）同样无效——那是更“干净”的分布，也没能改变量化后的注意力。

### D. 口径提醒

训练内 KL（末轮 ≈ 60）与离线 KL（12 层 × 3.66 ≈ 44）不是同一个聚合口径，且训练侧带 MixUp 关闭但仍有 rand-augment / random-erasing，两者只能看**趋势**、不能直接比数值。这和此前 `mass_error` 训练报 0.007、离线测 0.084 的口径问题是同一类。

**判定建议**：以后所有“学生是否学到教师分布”的结论，一律用**离线同口径 KL + 离线注意力 top-1/top-5 重合率**作为唯一判据，训练内 loss 只作为优化健康度信号。

## 5. 存疑 / 必须先查清的口径问题

1. **训练内诊断与离线复测严重不一致**（最要紧）
   - `attn_rowmass` 训练日志（epoch 18 + val）报 `mass_error=0.007`、`post_zero_rate=0.1928`；
   - 我在同一 `last.pth.tar` 上用 hook 直接测：行质量 0.720（相对误差平方 0.084）、零占比 72.3%。
   - 差了一个数量级 → 训练里的 fidelity/val 诊断与离线 hook 抓的**不是同一个张量/口径**（可能是 post-quant renorm 前后、或 train/eval 分布差异）。在查清之前，任何“注意力量化保真度”的数字都不能跨实验比较。
2. **FP 注意力 14.39 需要反向控制**：现在是“换掉就崩”，严格说只能证明“网络依赖该尺度”。建议补一个 **FP 注意力从头训 2 epoch** 的对照，排除 eval 路径本身有 bug。
3. **基线缺 uniform W3A3 / W4A4 控制**，61.64 的对外表述受限（见 3.3）。
4. 两处小事故：`attn_loguniform` 首跑在 epoch 0 被中止（`np.log`/校准问题后改 retry）；`teacherkl_15pct_20ep_sched20` 跑完 20 轮但没写 `exit_status`（收尾时被杀，数值可用）。

## 7. 建议的下一步（按性价比排序）

1. **补 uniform W3A3（以及 W4A4）同协议控制**，4 卡 ≈ 5.3 h/条。这是把 61.64 变成可发表结论的唯一缺口。
2. **查清 5.1 的口径不一致**（半天工作量，纯读代码 + 单卡复测），否则注意力那条线的所有数字都要重做。
3. **把“非归一化量化注意力”作为方法的一部分显式建模**：与其事后加 row-mass 正则丢 2.5 分，不如直接训练一个 `{0,s,2s}` 且**自带行归一化**的量化器（等价于硬件友好版本），看这 2.5 分能不能靠更长 epoch / 更好的码本拿回来；同时它让 FP/renorm 消融不再是灾难。
4. **深度 profile 上 100 epoch 验证**：20 epoch 的差距（+8.6）可能被长训练压缩或放大，但论文主表必须至少 100ep；建议先跑 `[4,4,3,2,T×4,2,3,4,4]` 与 uniform W3A3 各一条。
5. 注意力辅助目标先停：四条零/负收益，且本轮已证明瓶颈在“质量”而非“形状”。
