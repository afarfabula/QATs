# OFQ 200epoch 固定周期 Sparse Prev-step KL 实验记录

## 给导师看的摘要

这是一条从 ImageNet 预训练 Swin-T 出发、完整训练 200epoch 的 OFQ/QAT 长跑实验。核心变量不是更换量化器或做 checkpoint 后处理，而是在原版 OFQ 训练范式上加入固定周期、非常稀疏的 prev-step attention relation KL，用它抑制少数高风险 attention head 的关系分布震荡。

实验完整产生 200 次 full ImageNet validation，每次都是 50000 samples。最好单 checkpoint Top-1 为 `80.8680`，出现在第 195 次 validation；最终 checkpoint Top-1 为 `80.7080`。结果高于当前已整理到的 100epoch no-KL from-scratch control 和 200epoch sparse-KL resume 记录，但尚未达到 `81%`，也还缺少严格同设置的 200epoch no-KL from-scratch 对照，因此目前只能说明该固定周期 sparse prev-step KL 训练稳定、后期仍有收益，不能单独证明收益全部来自 KL。

## 实验目标

本实验用于验证一个不依赖 validation accuracy 触发时机的 Attention relation 震荡抑制方案：从 ImageNet 预训练 Swin-T 直接做 200epoch OFQ QAT，在训练中按固定 epoch 周期开启非常稀疏的 prev-step attention KL，观察其是否能在长训练中超过原版 OFQ/public-family 基线。

本文档重点记录算法设计、实验口径、完整 validation 轨迹和结果分析；代码路径仅作为可复查证据，不展开实现细节。

核心约束：

- 不使用 checkpoint soup、平均权重、ensemble 或多 checkpoint 拼接。
- 不使用 A8 到 A4 的阶段式方案。
- 不使用 validation accuracy 判断 KL 开启时机。
- KL 只作为固定日程的 sparse regularization，不做动态搜索。
- 单 checkpoint 结果为准，full validation 必须是 ImageNet 50000 samples。

## 实验变量和控制变量

本实验的核心自变量是 `fixed-cycle sparse prev-step attention KL`。其余训练因素尽量沿用当前 OFQ/public-family 口径，避免把训练长度、蒸馏、增强、量化器和 KL 的贡献混在一起。

固定不变的训练口径：

- 仍然使用 OFQ 主链路，不使用新的量化器范式。
- 仍然是 Swin-T，ImageNet full train/val。
- 仍然使用 teacher soft KD，teacher 为 ImageNet 预训练 Swin-T。
- 仍然是 W4A4-family：权重和激活主量化为 4bit，`wq=statsq`，`aq=lsq`，`qk_reparam=true`。
- 不使用 checkpoint soup、权重平均、ensemble 或多 checkpoint 拼接。
- 不使用 validation accuracy 决定 KL 开关，KL 开启时机完全由预先写死的 epoch 日程决定。

本次新增的算法变量：

- 引入一个 prev-step reference model。
- 只约束少数预先选择的 layer/head attention relation。
- KL 以固定周期脉冲方式开启，而不是每个 epoch 常开。
- 中后期略提高 primary pulse 权重，最后 30epoch 再降低权重做稀疏 polish。

## 算法设计细节

### 基本思想

此前动态 sparse prev-step KL 的问题是容易和 validation trajectory 绑定，导师明确不允许用 val acc 决定 KL 时机。因此这次实验改为固定周期：

- 使用 prev-step reference model。
- KL 目标是 attention relation 相关的 `kl_ref`。
- 只在预设 epoch 打开 KL，其余 epoch 完全关闭。
- KL head 只选择少量高风险 head，不对所有 head 全量约束。
- late stage 进一步降低 KL 频率和权重，避免过强正则压制收敛。

### KL 约束对象

这里的 KL 不是分类 logits KL，也不是对全部 Q/K/V feature 做 MSE。它约束的是 Swin attention 内部已经 softmax 后的 attention relation distribution：

```text
student attention probability  vs.  prev-step reference attention probability
```

可以把它理解成：当前量化模型在某个 attention head 上产生的 token-to-token 关系分布，不要相对上一段训练状态突然大幅漂移。这样做的动机是，W4A4 QAT 中 attention relation 对量化扰动非常敏感，直接压所有层、所有 head 会变成强正则，容易压制正常收敛；只压历史统计里更容易震荡的少数 head，目标是降低震荡而不是固定整个网络。

具体口径：

- KL 使用 `kl_ref`，方向是 student distribution 对 prev-step ref distribution 做一致性约束。
- 约束对象是选中 head 的 attention probability，而不是所有 layer 的 QK raw score。
- `5:7` 表示第 5 个 attention layer 的第 7 个 head；同理 `4:11`、`8:4` 等都是 `layer:head`。
- 当一个 epoch 的 head 列表为 `5:7,4:11,8:4` 时，只对这 3 个 layer/head pair 计算 attention KL，然后按选中 head 求平均。
- 未被选中的 layer/head 不加这个 prev-step attention KL，仍然只接受主训练损失和 teacher KD 的梯度。

### KL 参数

```text
train_scheme: ema_ref_attn_kl
ref_update: prev_step
ref_update_interval: 50
ref_attn_loss: kl_ref
base ref_attn_kl_weight: 0.0
ref_attn_kl_drop_prob: 1.0
ref_attn_kl_clip: 20.0
ref_warmup_epochs: 0
```

注意：虽然 `ref_attn_kl_drop_prob=1.0`，实际开启 KL 的 epoch 由 `ref_attn_kl_weight_epoch_overrides` 和 `ref_head_mode_epoch_overrides` 控制。日志中有 `RefW` 和 `RefAttnKL` 字段，可用于核对哪些 epoch 实际非零。

### Head 选择

primary heads：

```text
5:7,4:11,8:4
```

primary + secondary heads：

```text
5:7,4:11,8:4,11:18,6:1
```

设计逻辑：

- primary heads 作为主要高风险 attention relation 震荡 head。
- secondary heads 只在少数中后期脉冲中加入，用于覆盖额外不稳定 head，但避免大面积约束。
- 不使用 validation accuracy 做 head 或时机选择。

### 固定周期日程

训练内部 epoch 是 0-based。下表用 1-based 人类可读 epoch 描述：

| 阶段 | KL 日程 | Head | Weight |
|---|---|---|---:|
| epoch 1-40 | 不开 KL | 无 | 0 |
| epoch 41-120 | 每 8 个 epoch 开 2 个 epoch | primary | `1e-5` |
| epoch 121-170 | 每 8 个 epoch 开 2 个 epoch | primary 为主；每第三个 pulse 用 primary+secondary | primary `1.5e-5`；secondary pulse `1e-5` |
| epoch 171-200 | 每 10 个 epoch 开 1 个 epoch | primary | `5e-6` |

| 范围 | KL-on epochs | KL-on ratio | 设计含义 |
|---|---:|---:|---|

## 观察和分析

1. 训练后半程仍有缓慢收益。

   从分段平均看，`161-200` 的平均 Top-1 为 `80.7061`，高于 `121-160` 的 `80.5691`。这说明 200epoch 长跑并非完全无效，后半程仍在缓慢改善。

2. 最佳点出现在很晚的第 195 次 full validation。

   这支持“长 run 才能验证 sparse KL 是否有效”的判断。短于 100epoch 的实验很难覆盖 late polish 阶段，也容易误判固定周期 KL 的收益。

3. 最终 checkpoint 比 best checkpoint 有回落。

   Best 是 `80.8680`，final 是 `80.7080`，回落 `0.1600`。因此汇报时应同时报告 best 和 final，不能只报最终。

4. KL 设计比较保守。

   KL 只在固定 epoch 开启，且 late stage 权重降到 `5e-6`。这避免了明显训练崩溃，但也可能不足以突破 81。

5. 当前证据不足以证明 KL 本身优于 no-KL 200epoch。

   已有 no-KL 对照只有 100epoch from-scratch 和 resume10->110。由于本实验训练 200epoch，最关键的下一个实验应是同口径 200epoch no-KL control。

## 初步结论

这次 200epoch fixed-cycle sparse prev-step KL 实验是目前较好的长跑结果之一：

```text
best Acc@1 = 80.8680
final Acc@1 = 80.7080
```

它没有达到 `81%`，但相对于现有 100epoch no-KL 和 200epoch sparse KL resume 记录略高。最重要的结论不是“已经证明 KL 有效”，而是：

- 固定周期 sparse prev-step KL 没有破坏长跑稳定性。
- 200epoch 后期仍能出现更高 checkpoint，best 出现在 validation index 195。
- 当前缺少严格同设置的 200epoch no-KL 对照，导致无法定量拆分“训练更久”和“KL 正则”的贡献。

## 下一步建议

为了给导师一个清楚的 ablation，下一步应补跑：

```text
ofq_200ep_fromscratch_original_ofq_public_control
```

要求：

- 复用本实验的数据、teacher、batch size、LR、scheduler、KD、augmentation、QKR、StatsQ/LSQ、bf16 AMP。
- 移除所有 `train_scheme ema_ref_attn_kl`、`ref_update prev_step`、`ref_attn_*`、`ref_head_*` 参数。
- 保持 200 个 full validation rows。
- 对比 best、final、last20 avg、last40 avg、以及 160-200 阶段均值。

这条 no-KL 200epoch 对照完成后，才能判断 sparse prev-step KL 的真实贡献。
